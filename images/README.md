# 🖼️ Canva 이미지 넣는 곳

웹앱 카드에 보이는 그림은 이 폴더의 이미지 파일을 사용합니다.
**파일이 없으면 자동으로 이모지 타일**로 보이므로, 만든 그림부터 하나씩 넣어도 됩니다.

## 넣는 방법

1. [Canva](https://www.canva.com)에서 **Magic Media(텍스트로 이미지 만들기)** 를 열고 아래 *Canva 프롬프트* 를 붙여 넣어 이미지를 만듭니다.
   - 권장 크기: **가로형 400 × 260 px** (3:2 비율) · 밝은 배경의 플랫 일러스트
2. **PNG** 로 다운로드합니다.
3. 아래 표의 **파일 이름 그대로** 이름을 바꿔 이 `images/` 폴더에 넣습니다.
4. 커밋·푸시하면 웹앱 카드에 바로 나타납니다.
